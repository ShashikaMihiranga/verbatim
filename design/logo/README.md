# Verbatim logo (3D bars)

Direction chosen: option H, isometric bars in theme colours.

- `logo-mark.svg`: mark only, for light backgrounds. `logo-mark-on-dark.svg`: gaps match the ink background. `logo-mark-white.svg`: one-colour white, gaps match the teal accent (#0f6688).
- `logo-lockup*.svg`, `logo-stacked.svg`: mark plus the word. The wordmark is live text set in Jost 600, so it needs Jost installed or loaded; convert to outlines before using it outside the app.
- `app-icon.svg`, `app-icon-light.svg`: 512 px full-bleed squares (the OS rounds the corners). `favicon.svg`: rounded ink tile.

Colours: bars #3f8a57, #2680c7, #26cbd8, #43b895. Ink #12303a. Accent #0f6688. Light faces mix 68% bar colour with white; right faces mix 70% bar colour with ink.

Rules: clear space equals one bar width on every side. Minimum mark size 24 px; below that use the app icon tile. Do not recolour or reorder the bars, add shadows or gradients, or stretch the mark.
